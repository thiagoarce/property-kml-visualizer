# Property KML Visualizer

Visualizador local de arquivos KML para planejamento geográfico, sem instalações no computador do usuário.

> **Privacidade:** este repositório é público e contém **apenas código e dados inteiramente fictícios**. Nunca publique aqui KMLs institucionais, planilhas, dados pessoais, fotos ou documentos internos.

## Objetivo

- Abrir um arquivo HTML no Edge com dois cliques.
- Importar um KML local por seletor ou arrastar/soltar; analisar tudo dentro do navegador.
- Renderizar mapa, marcadores, grupos e informações sem enviar os dados para APIs externas.
- Utilizar cartografia OpenStreetMap online quando autorizada; essa cartografia recebe pedidos de tiles por área/zoom, **não recebe o KML**.
- Fornecer um pacote HTML único, sem instalador, Python ou execução de servidor no computador do destinatário.

## Estado

Estrutura inicial. Consulte a branch de desenvolvimento para a primeira versão usando Leaflet.

## Política de dados

Não use KMLs reais em issues, pull requests, commits, capturas de tela ou ferramentas de IA não autorizadas. Testes automatizados e exemplos devem ser sintéticos.
